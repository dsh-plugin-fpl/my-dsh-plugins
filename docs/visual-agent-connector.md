# 独立视觉工坊 Agent 连接器

`dsh-fpl-visual-workshop` 独立发布 DSH 工具与操作 Skill，连接用户已启动的视觉工坊。工坊继续拥有项目、画布、输出及任务；公共执行仍由 Core 提供。连接器启停不控制业务进程，不读取业务数据库。

首版完成项目绑定、画布编辑、生成任务查询、Harness 图片附件和最终输出选择；默认聊天卡片显示附件引用，可在“查看／轨迹”的工具结果中查看缩略图和原图。绑定与任务 ID 按会话及凭据身份保存。旧连接器和新连接器不得同时启用，避免工具名和应用登记冲突。

连接器 0.1.1 支持 Harness 0.2.2-rc.1／rc.5；Core DSH 的应用目录登记可选。受限预览要求 visual-workshop `4dc27f4` 起，公开连接凭据导出命令要求 `75a0e3c` 起。接口契约由提供方维护，新增 Gateway 预览不改变原有应用业务接口。0.1.1 已通过日常桌面 DSH 的正常插件管理安装并启用；未发布 npm。

隔离验收使用真实工坊、嵌入 Core 和确定性模型替身，实际插件包经 Harness 原生工具执行链完成生成与选用；浏览器验证图片查看和刷新恢复。Harness 侧 Core 应用登记使用夹具，完整日常 Core 插件目录注册及付费模型效果未覆盖。详见连接器的 [验收记录](../dsh-fpl-visual-workshop/docs/acceptance.md)。

桌面安装验收：rc.5 隔离原生执行链注册 15 个视觉工具并认证读取现有项目；日常桌面组件显示“运行中”。通过公开 `connect-agent` CLI 导出私有凭据，连接器配置命令核验端点后保存定位，不手改 profile。安装期间未生成内容或修改项目。
