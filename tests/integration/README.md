# 跨插件联动验收

当前只有文档脚手架，没有跨插件业务实现或已通过的业务验收。

后续每条真实链路应明确插件版本组合、前置配置、隔离测试数据、命令或操作步骤、预期结果及可复核证据。测试代码与用例说明归本目录；可再生成的截图、日志、测试数据放已忽略的 .local/<任务>/，不要提交凭据或真实业务数据。

第一条链路建议验证公共配置、授权、模型或 Agent 接入与一个真实应用；覆盖资源交接、提交超时后结果核对、重复请求、取消、部分失败、重启恢复、缺少可选插件以及兼容升级。等真实能力可用后再添加实现，不用空测试充当通过。

管理脚本的隔离 Git 测试位于上一级 tests 目录，只证明工作区工具行为。
