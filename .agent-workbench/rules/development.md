# 开始与落盘

- 默认从本仓库根目录开展整套开发。Python 命令优先使用 `uv run --no-project python`，也可直接使用 Python 3.10+。
- 先运行 `scripts/workspace.py status`，检查总仓库和相关插件的分支、修改与固定版本差异。总仓库及插件默认都直接在各自的 `main` 分支修改和提交，不创建任务分支或额外 worktree。若尚未检出 `main`，且工作区干净，切换到已有 `main`；若有未提交改动，先保留现场并报告，不 stash、覆盖或擅自改在其他分支提交。保留用户已有改动。
- 临时输入、截图、诊断和验收克隆放 `.local/<任务>/`，创建前用 `git check-ignore` 确认；正式运行状态与本地配置放 `.runtime/`。正式代码、服务工作目录和运行依赖不得指向 `.local/`。
- 凭据、真实账号数据、运行数据不得提交或输出。测试使用隔离配置和临时仓库，不改真实持久数据。
